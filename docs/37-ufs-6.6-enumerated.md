# 37 — UFS 6.6 enumerado en ruby

Fecha: 2026-10-21

## Resultado

El kernel 6.6.127 del A34, con DTB stock de ruby parcheado y los módulos de
diagnóstico, ya enumera el almacenamiento UFS:

```
ufshcd-mtk 11270000.ufshci: UFS link start-up passes
scsi 0:0:0:0:  SKhynix H9QT1G6DN6X132 A003
scsi 0:0:0:2:  [sdc] 62480384 4096-byte logical blocks (256 GB)
sd 0:0:0:2: [sdc] Attached SCSI disk
sdc: sdc1 sdc2 ... sdc77
```

`/dev/sdc1` es `misc`; `/dev/sdc61` es `super`; `/dev/sdc76` es `userdata`
según `/dev/block/by-name` del Android stock.

## Cadena resuelta

1. **pinctrl**: el nodo `/pinctrl` de ruby 4.19 usa `reg_bases`; el driver 6.6
   exige `reg` + `reg-names` con 9 bases:
   `0x10005000, 0x11c20000, 0x11c30000, 0x11d10000, 0x11d30000,
   0x11d40000, 0x11e20000, 0x11ea0000, 0x11f30000`.
2. **EINT**: añadir `mediatek,eint = <&eint>` al pinctrl y, en
   `eint@1000b000`:
   ```
   reg-name = "eint";
   mediatek,total-pin-number = <128>;
   mediatek,instance-num = <1>;
   interrupts = <0 256 4>;   /* GIC_SPI 256, level high */
   ```
   Sin `interrupts`, `mtk_eint_do_init()` aborta con `IRQ parse fail` y no
   crea el dominio IRQ; el PMIC queda en `IRQ index 0 not found`.
3. **PMIC**: `mt6359-pmic` debe poder matchear el MFD `mt6397` de 6.6. Se usa
   `compatible = "mediatek,mt6359-pmic", "mediatek,mt6359p"`.
4. **Reset**: cargar `reset-ti-syscon.ko`; sin él el UFS espera
   `10001000.syscon:reset-controller`.
5. **UFS**: la primera prueba sin reguladores usó el workaround de quitar
   `vcc-supply`; el driver asumió `vcc` encendido y enumeró. Después se
   restauró `vcc-supply` y se añadió `regulator-compatible = "ldo-vemc"` /
   `"ldo-vufs"`; el UFS volvió a enumerar. El `regulator_summary` todavía no
   muestra todos los rails, así que el regulador sigue pendiente de limpieza.

## Particiones comprobadas

Con espera de 2 s tras cargar los módulos y fallback por número de partición:

```
super     /dev/sdc61  PART_OK
userdata  /dev/sdc76  PART_OK
metadata  /dev/sdc13  PART_OK
vbmeta_a  /dev/sdc7   PART_OK  magic AVB0
misc      /dev/sdc1   PART_OK
```

`find_partition()` por `PARTNAME` no basta en este initramfs porque corre antes
de que UFS enumere; el fallback crea el nodo de bloque desde
`/sys/class/block/sdcN/dev`.
